# Tarefa HTML - In Junior

Este repositório contém um projeto front-end desenvolvido em grupo como tarefa na IN Junior, com foco nos fundamentos de **HTML**. O projeto é um site coletivo do grupo **Nova Pixel**, composto por uma página principal e páginas individuais de cada integrante.

## Objetivo

Praticar os conceitos essenciais de HTML, como:

- Estruturação semântica de páginas (`header`, `main`, `section`, `nav`, `footer`)
- Criação de links internos entre páginas
- Uso de listas ordenadas e não ordenadas
- Formulários com `textarea`, `input` e `button`
- Incorporação de imagens e iframes (Google Maps)
- Navegação entre múltiplas páginas HTML

## 📋 Sobre o projeto

O **Nova Pixel** é um site coletivo criado pelo grupo de três integrantes durante o processo seletivo da IN Junior. O site é composto por:

- **Página Principal** — apresentação do grupo, missão e valores, com links para as páginas individuais de cada membro
- **Páginas Individuais** — cada integrante tem sua própria página com foto, biografia, lista de hobbies, top 5 de jogos favoritos e formulário de feedback
- **Páginas de Contato** — páginas de contato individuais de cada membro

## 🚀 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/marcosgomes-dev/Tarefa-HTML---InJunior.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd Tarefa-HTML---InJunior
   ```
3. Abra o arquivo `Tarefa de HTMl/principal/principal.html` no navegador para ver a página principal.

Recomenda-se usar a extensão **Live Server** do VS Code para garantir que os links entre páginas e as imagens funcionem corretamente.
